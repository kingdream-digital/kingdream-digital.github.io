# Créations & démos — KingDream Digital

**https://kingdream-digital.github.io/**

Vitrine publique des sites et démos réalisés par KingDream Digital.

Ce dépôt ne contient que les sites terminés. Ils sont publiés depuis le
dépôt privé `Client` avec son script `publier.py` : faire les modifications
dans `Client`, pas ici.

Exceptions, gérées hors du dépôt `Client` (à ne pas effacer lors d'une publication) :
- `deep-clean/v2/` et `deep-clean/site/` : copies des démos du dépôt privé `deep-clean` ;
- `instagram/` : images des posts Instagram, déposées automatiquement par le robot du dépôt
  privé `boriscorsiez/kingdream-digital` juste avant chaque publication.
